# 课表导入程序

这是一个 Windows 本地小工具：可以粘贴中英文课表文字，也可以选择课表图片自动识别文字，然后生成 Apple 日历可以导入的 `.ics` 文件。

## 怎么用

1. 双击 `启动课表导入程序.bat`。
2. 任选一种方式导入课表：
   - 直接粘贴课表文字。
   - 点击 `从图片识别`，选择课表截图或照片。
3. 确认年份，例如 `2026`。
4. 点击 `预览识别结果`，或图片识别完成后，在弹出的确认窗口里检查课程表；跨周课程可向下滚动查看。
5. 可以修改课程日期、开始时间、结束时间、课程名称和地点，也可以在表格末尾新增课程或删除误识别的课程。日期请填写 `yyyy-MM-dd`。
6. 点击 `确认并更新` 后，再点击 `生成 ICS 文件`，选择保存位置。
7. 在 iPhone / Mac 的日历里导入这个 `.ics` 文件。

## 图片识别小建议

- 尽量使用清晰截图，比拍照更稳。
- 图片里最好只保留课表区域，少放其他无关文字。
- 对网页课表截图，程序会优先识别绿色课程块，并按星期列重组课程，水印、表格线、空白格会尽量忽略。
- 如果 OCR 把某个字、时间或教室识别错了，可以直接在文字框里手动改，再预览和导出。
- 图片识别使用 Windows 本地 OCR，不需要联网。如果电脑缺少中文或英文 OCR/语言功能，程序会提示你安装。

## 中文格式

也支持类似下面的中文日期和时间：

```text
星期一 1月26日
高等数学 讲座
14:00 - 16:50
教室：AC3-214
周二 1月27日
计算机科学 实验
上午8:30 - 10:20
地点：电脑室 AC1-201
```

## 支持的文字格式

每一天先写日期，然后每节课按三行写：

```text
Monday, Jan 26
GE 2410 Lecture
2:00 PM - 4:50 PM
Room: Classroom, AC3-214
```

同一天有多节课时，继续往下写即可。没有地点时，`Room:` 行可以留空或省略。

## 小提醒

程序会按你填写的年份和文字里的月日生成日期。比如 `Jan 28` 加上年份 `2026`，就是 `2026-01-28`。

如果文字里的星期几和这个年份的真实星期几不一致，程序仍然会按月日导出，并在预览里提醒你。
